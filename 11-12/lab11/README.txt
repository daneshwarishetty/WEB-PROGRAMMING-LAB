LAB 11 - DISPLAY CURRENT DATE, TIME AND DAY USING PHP

Project files:
1. index.php  - PHP logic and HTML page.
2. style.css  - Separate stylesheet for page design.

Features:
- Displays the current date.
- Displays the current time in 12-hour format.
- Displays the current day of the week.
- Uses Asia/Kolkata timezone.
- Responsive design with a green, cream and mint colour theme.
- Footer credit: Daneshwari Kuruvinashetty.

HOW TO RUN USING XAMPP:
1. Install and open XAMPP.
2. Start Apache.
3. Copy the extracted project folder into C:\xampp\htdocs\
4. Open this address in your browser:
   http://localhost/Daneshwari_Lab11_Current_Moment/index.php

IMPORTANT:
Do not double-click index.php to run it. PHP must be processed by a server.
The date and time are generated when the page is loaded or refreshed.
