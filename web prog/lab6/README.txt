LAB 6 — VIJAYAPURA TRAVEL DESTINATION
=======================================

PROJECT FILES
-------------
1. index.html  - Main webpage content and structure
2. style.css   - External CSS stylesheet (all design and formatting)
3. script.js   - Small navigation accessibility enhancement

HOW TO OPEN
-----------
1. Extract this ZIP file.
2. Keep index.html, style.css and script.js together in the same folder.
3. Double-click index.html to open the website in Chrome or another browser.
4. To view/edit the code, right-click a file and choose Open with Notepad
   or open the folder in Visual Studio Code.

IMPORTANT
---------
- This project uses external CSS through: <link rel="stylesheet" href="style.css">
- The hero background and four monument photographs load from external image
  URLs, so an internet connection is required to display the photos.
- Photos shown: Gol Gumbaz, Ibrahim Rauza, Bara Kaman and Gagan Mahal.
- The page has no travel agency branding, sponsor logos or third-party logos.
- Monument descriptions are a student-friendly overview, not a complete
  archaeological inventory. Access to some heritage/religious sites can vary.
