LAB 12 - AGE ELIGIBILITY CHECK (PHP)

Files:
- index.php : HTML form and PHP age-checking logic
- style.css : Responsive page styling

How to run using XAMPP:
1. Extract this ZIP file.
2. Copy the folder "Daneshwari_Lab12_Age_Eligibility" into:
   C:\xampp\htdocs\
3. Open XAMPP Control Panel and start Apache.
4. Open this URL in your browser:
   http://localhost/Daneshwari_Lab12_Age_Eligibility/index.php

Expected output:
- If age is below 18: "Hello, [name], you are not authorized to visit the site."
- If age is 18 or above: "Welcome to this site, [name]!"

Note:
Run the PHP file through localhost with Apache. Do not open index.php by double-clicking it.
MySQL is not required for this program.
