JAIN (DEEMED-TO-BE UNIVERSITY) - LAB 5
========================================

Files included:
1. index.html       - Webpage structure and content
2. style.css        - Background image, colours, fonts and layout
3. script.js        - Pauses the scrolling announcement on mouse hover
4. Background image loads from the Jain University website URL supplied for this assignment.

HOW TO RUN:
1. Extract this ZIP file.
2. Keep all the files in the same folder.
3. Double-click index.html to open the webpage in a browser.
4. To view the source code, right-click a file and open it with Notepad
   or Visual Studio Code.

The page uses HTML, external CSS and JavaScript.
