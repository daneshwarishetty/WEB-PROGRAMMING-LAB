LAB 7 - JAVASCRIPT CALCULATOR

Files included:
1. index.html  - Calculator page structure and form buttons
2. style.css  - Layout, colors, spacing and responsive styling
3. script.js  - Calculator operations and keyboard support

HOW TO RUN:
1. Extract the ZIP file.
2. Open the Lab7_Calculator folder.
3. Double-click index.html (or open it in a web browser).
4. Use the on-screen buttons or your keyboard.

FEATURES:
- Addition (+), subtraction (-), multiplication (×), division (÷)
- Decimal numbers, percentage and positive/negative toggle
- All Clear (AC) and delete last digit
- Keyboard support
- Division-by-zero error handling
- Responsive design for mobile and desktop

No installation or internet connection is required.
