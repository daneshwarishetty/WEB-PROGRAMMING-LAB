LAB 8 - USER INFORMATION FORM USING JAVASCRIPT

FILES INCLUDED:
1. index.html   - Registration form to collect user information
2. display.html - Separate page to display submitted information
3. style.css    - External CSS styling for both pages
4. script.js    - Form validation and data transfer
5. display.js   - Reads and displays submitted information
6. README.txt   - Project instructions

HOW TO RUN:
1. Extract Lab8_User_Information.zip.
2. Open the extracted Lab8_User_Information folder.
3. Double-click index.html to open the form in a browser.
4. Enter all details and click Submit Information.
5. The browser opens display.html and shows the submitted details.
6. Click Back to Form to return to the registration page.

FORM FIELDS:
- Full name
- Gender
- Mobile number
- Email ID
- City
- State
- Country

JAVASCRIPT CONCEPTS USED:
- Form submit event and preventDefault()
- Reading form element values
- Input validation using regular expressions
- sessionStorage to transfer data between pages
- DOM manipulation to display information on another page

NOTE:
The data is stored temporarily in the current browser tab using sessionStorage.
It is not sent to a server or stored in a database.
