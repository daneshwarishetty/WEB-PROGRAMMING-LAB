DANESHWARI KURUVINASHETTY - SESSION MANAGEMENT WEB PROJECT

Files included:
- index.html: login, welcome and logout page structure
- style.css: lavender and blue responsive design
- script.js: sessionStorage name/time handling and duration calculation

How to run:
1. Extract the ZIP file.
2. Keep all three files in the same folder.
3. Open index.html in a browser, or run the folder using VS Code Live Server.
4. Enter a name, click Continue, then click Log out to see the duration.

Note: This supplied version uses browser sessionStorage (client-side session),
not Java HttpSession/Servlet sessions. It is a front-end HTML/CSS/JavaScript version.
