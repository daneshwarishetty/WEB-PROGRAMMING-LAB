BOOK WORLD - BOOK INFORMATION WEBSITE

This project demonstrates a two-frame website.
- index.html: frameset dividing the page into left and right sections
- books.html: left-side book list; links load into rightFrame
- home.html: welcome page shown on the right initially
- book1.html to book5.html: individual book information pages
- style.css: shared styling

To run: Keep all files in the same folder and open index.html in a browser.
Note: HTML frames/frameset are obsolete in modern HTML, but are used here because the assignment specifically asks for frames.
