LAB EXPERIMENT 2 — PRODUCT INFORMATION TABLE

Files:
- index.html: webpage structure and product table
- style.css: page styling and responsive layout
- script.js: live product search and current year
- images/: generated product images used in the table

How to run:
1. Extract the ZIP file.
2. Open index.html in any web browser.
3. Use the search box to filter products by name or brand.

The product names, specifications and prices are sample details for the lab exercise.
